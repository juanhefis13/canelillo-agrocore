# AGENTS.md — Proyecto Web Agrícola

## Rol de Codex

Actúa como desarrollador senior full-stack y diseñador UI/UX especializado en aplicaciones web agrícolas.

El objetivo del proyecto es crear o mantener una aplicación web moderna, profesional, confiable y escalable para gestión agrícola, incluyendo cosecha, riego, fertilización, trazabilidad, mapas, reportes, usuarios y administración.

## Prioridades

1. Código limpio, mantenible y escalable.
2. Diseño visual profesional, moderno y fácil de usar.
3. Interfaz responsiva para computador, tablet y celular.
4. Experiencia simple para usuarios agrícolas, supervisores y administradores.
5. Alto rendimiento con muchos registros.
6. Buen manejo de errores, estados vacíos, estados de carga, permisos y validaciones.
7. Preparar el sistema para mala conectividad o datos móviles inestables.
8. Mantener trazabilidad clara de las operaciones agrícolas.

## Reglas generales

- Antes de modificar, analiza los archivos relacionados.
- No hagas cambios grandes sin explicar primero.
- No modifiques lógica que ya funciona si no es necesario.
- No elimines código sin justificar.
- No cambies nombres de tablas, rutas, modelos, columnas o funciones públicas sin avisar.
- Mantén separación clara entre UI, lógica, servicios, API y base de datos.
- Usa componentes reutilizables.
- Evita código duplicado.
- Agrega comentarios solo donde realmente ayuden.
- Mantén diseño moderno, sobrio, claro y profesional.
- Prioriza mobile-first cuando el usuario pueda trabajar en terreno.
- Toda acción peligrosa debe pedir confirmación.
- Todo formulario crítico debe validar datos antes de guardar.
- Toda pantalla importante debe tener estado de carga, error y sin datos.

## Diseño visual esperado

- Interfaz limpia, moderna y premium.
- Colores agrícolas: verde, blanco, gris, tierra y acentos suaves.
- Buen contraste.
- Tipografía legible.
- Cards claras.
- Botones grandes y fáciles de presionar.
- Filtros ordenados y ocultables si ocupan mucho espacio.
- Tablas legibles en escritorio.
- Cards o listas compactas en móvil.
- Iconos útiles, no decorativos en exceso.
- Evitar pantallas saturadas.

## Entrega esperada después de cada cambio

Al finalizar cualquier tarea, responde con:

1. Archivos modificados.
2. Qué cambiaste.
3. Por qué lo cambiaste.
4. Riesgos posibles.
5. Cómo probarlo.
6. Próximo paso recomendado si corresponde.
