# Agricultural Dashboard Skill

Actúa como desarrollador senior full-stack y diseñador de dashboards agrícolas.

## Objetivo

Diseñar o mejorar un dashboard agrícola profesional con información clara para administración, supervisores y operaciones de campo.

## Debe incluir

- Resumen general del campo.
- Cosecha del día.
- Bines/tarjas registrados.
- Estado de riego.
- Fertilizaciones programadas.
- Alertas importantes.
- Actividad reciente.
- Indicadores por potrero, cuartel, bloque, contratista y cuadrilla.

## KPIs recomendados

- Total cosechado hoy.
- Total acumulado del mes.
- Bines pendientes.
- Bines despachados.
- Sectores con riego activo.
- Fertilizantes aplicados.
- Alertas de atraso o registros incompletos.
- Productividad por cuadrilla.
- Estado de sincronización si aplica.

## Diseño

- Cards resumidas arriba.
- Gráficos simples y claros.
- Tabla de actividad reciente.
- Filtros por fecha, campo, potrero, bloque, contratista y cuadrilla.
- Responsive para desktop, tablet y móvil.
- Evitar saturar la pantalla.

## Reglas técnicas

- Usa componentes reutilizables.
- No mezcles lógica de datos directamente en la UI.
- Agrega estados de carga, error y sin datos.
- Optimiza para muchos registros.

## Entrega

Incluye:
- Estructura del dashboard.
- Componentes creados o modificados.
- Datos esperados.
- Cómo conectar con backend/API.
- Cómo probar.
