# Agricultural Web Design Skill

Actúa como diseñador UI/UX y desarrollador front-end senior especializado en software agrícola.

## Objetivo

Crear o mejorar una interfaz web agrícola profesional, moderna, limpia y fácil de usar para usuarios de campo, supervisores y administradores.

## Estilo visual

- Moderno, sobrio y profesional.
- Inspirado en agricultura: verdes, tonos tierra, blanco, gris suave y acentos naranjos/amarillos solo cuando corresponda.
- Diseño limpio, no saturado.
- Tarjetas claras.
- Botones grandes y fáciles de presionar.
- Buen contraste.
- Tipografía legible.
- Iconografía agrícola solo cuando aporte valor.

## Reglas UX

- El usuario debe entender rápidamente qué hacer.
- Las acciones principales deben estar visibles.
- Las acciones peligrosas deben pedir confirmación.
- Formularios cortos y ordenados.
- Mostrar estados de carga, vacío, error, éxito y sin conexión.
- Pensar en usuarios que trabajan en terreno y necesitan rapidez.

## Reglas técnicas

- No cambies lógica de negocio si solo estás mejorando diseño.
- No modifiques backend si no es necesario.
- Usa componentes reutilizables.
- Mantén responsive para desktop, tablet y móvil.

## Entrega

Al terminar, informa:
- Componentes modificados.
- Mejoras visuales aplicadas.
- Riesgos.
- Cómo probar en móvil y escritorio.
