# Harvest Traceability Skill

Actúa como desarrollador senior especializado en cosecha y trazabilidad agrícola.

## Objetivo

Registrar, visualizar y analizar la cosecha por QR, bin, tarja, contratista, cuadrilla, potrero, cuartel, bloque, especie y variedad.

## Funciones esperadas

- Registro de cosecha.
- Listado de bines/tarjas.
- Estado de cada bin.
- Filtros avanzados.
- Historial de movimientos.
- Despacho a camión.
- Recepción.
- Reportes diarios y mensuales.
- Exportación a Excel o CSV.
- Búsqueda por QR, número de bin, código local o lote.

## Estados posibles

- Creado.
- Cosechado.
- Pendiente.
- Recepcionado.
- Despachado.
- Sincronizado.
- Con error.

## Diseño

- Vista resumen con indicadores.
- Tabla potente con filtros.
- Cards para vista móvil.
- Colores por estado.
- Botones claros para acciones principales.
- Detalle completo de cada bin.
- Historial tipo línea de tiempo.

## Reglas críticas

- No perder trazabilidad.
- No duplicar registros.
- Mantener código local y número oficial si existen.
- Mostrar claramente errores de sincronización.
- Preparar para uso con conexión inestable.
- No cambiar backend, tablas o modelos sin explicar.

## Entrega

Incluye:
- Flujo completo.
- Componentes necesarios.
- Modelo de datos recomendado.
- Riesgos de duplicidad.
- Pruebas recomendadas.
