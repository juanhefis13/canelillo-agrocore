Politicas de privacidad

Uso de datos en Canelillo AgroCore y aplicaciones vinculadas.

Volver a AgroCore
Resumen

Los datos se usan para operar el campo, mantener trazabilidad agricola, generar reportes, visualizar mapas, controlar permisos y respaldar decisiones tecnicas. No se venden datos a terceros.

1. Responsable y alcance

El responsable operativo de esta plataforma es Agricola El Canelillo. Estas politicas cubren el uso de datos en AgroCore, Canelillo Harvest, Calicatas, Riego, Aplicaciones, Fertilizantes, Bodega, Monitoreo de plagas, Estacion climatica y cualquier modulo futuro conectado a la misma base de datos.

2. Datos que puede utilizar la plataforma

  • Datos de cuenta: nombre, correo, RUT, rol, area/app asignada y registros de acceso.
  • Datos agricolas: campo, potrero, bloque, especie, variedad, hectareas, plantas, caudal, precipitacion, horas base, labores y estados.
  • Datos operativos: cosecha, bines, cuadrillas, contratistas, aplicaciones, productos, dosis, bodega, riegos, programas, calicatas, plagas y reportes.
  • Datos tecnicos: fechas, horas, observaciones, auditoria de cambios, usuario que registra o modifica, archivos importados y sincronizacion con Supabase.
  • Datos de ubicacion y evidencia: coordenadas GPS, mapas, poligonos, fotos de calicatas, monitoreos o respaldos de labores cuando el modulo lo requiera.
  • Datos climaticos: temperatura, heladas, evaporacion, estacion, bandeja y calculos derivados como grados-dia o balance hidrico.

3. Finalidades de uso

La informacion se utiliza para planificar y controlar labores agricolas, comparar programas contra ejecucion real, mantener trazabilidad, generar indicadores, mapas y reportes, administrar usuarios, respaldar auditorias internas, mejorar la continuidad operacional y proteger la integridad de los registros.

4. Acceso, permisos y trazabilidad

El acceso depende del rol asignado. Los cambios relevantes pueden guardar fecha, usuario, modulo, origen del dato y observaciones. Los usuarios deben utilizar cuentas propias y no compartir credenciales.

5. Almacenamiento y proveedores

La informacion puede almacenarse en servicios cloud como Supabase y en archivos generados por la operacion, por ejemplo Excel, PDF, imagenes o respaldos. El uso de proveedores debe limitarse a funciones necesarias para autenticacion, base de datos, almacenamiento, reportes y seguridad.

6. Seguridad

La plataforma considera control de acceso, perfiles, politicas de base de datos, sincronizacion segura, respaldos y registro de cambios. Toda mejora futura debe mantener el principio de minimo acceso: cada usuario ve y modifica solo lo necesario para su labor.

7. Conservacion y eliminacion

Los datos operativos se conservan mientras sean necesarios para trazabilidad agricola, gestion interna, obligaciones administrativas, analisis historico y continuidad del campo. Cuando un dato ya no sea necesario, podra corregirse, anonimizarse, archivarse o eliminarse segun corresponda.

8. Derechos y solicitudes

Las personas autorizadas pueden solicitar revision, correccion, actualizacion o eliminacion de datos personales cuando proceda. Las solicitudes deben canalizarse con la administracion responsable del sistema para validar identidad, rol y alcance.

9. Cambios de estas politicas

Estas politicas pueden actualizarse cuando cambien los modulos, proveedores, procesos internos o normativa aplicable. La version visible en esta pagina sera la referencia operativa para usuarios de las aplicaciones.

Nota
